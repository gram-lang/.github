# Gram

**Gram** is a declarative recipe DSL: you write a recipe as plain text, and tools compile, scale, schedule, analyze and render it. Recipes as code.

Website and documentation: [gram-lang.org](https://gram-lang.org)

## Where things live

I develop Gram on my own [Forgejo instance](https://git.gram-lang.org/gram-lang), which is the canonical home of every repository in this organization.

[GitHub](https://github.com/gram-lang) and [Codeberg](https://codeberg.org/gram-lang) host read-only mirrors, kept up to date automatically.

## Issues and contributions

Issues and pull requests are handled on [Forgejo](https://git.gram-lang.org/gram-lang) only. Anything opened on a mirror cannot be merged there, so please start from the main forge.

Gram is maintained by one person, so replies may take a little time. Thank you for your patience.
